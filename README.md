# RestoApp

Сайт ресторана, который редоставляет пользователю следующие возможности:

- Просмотр меню с категориями.
- Ознакомление с новинками и популярными блюдами.
- Информация об акциях и событиях.
- Просмотр контактных данных и времени работы.
- Секция с нашими заведениями и зонами доставки.

## 🛠️ Стек
- HTML
- CSS
- JavaScript.

## 📂 Структура проекта

📁 project-folder\
├── 📁 images/ # Все изображения проекта\
├── 📁 styles/ # CSS файлы\
├── index.html # Главный файл HTML\
├── script.js # Скрипт, закрывающий баннер\
└── README.md # Описание проекта

## 🚀 Как запустить проект

1. Склонируйте репозиторий
   ```bash
   git clone https://github.com/tiredtiredness/RestoApp.git
   ```
2. Откройте файл index.html в браузере.
